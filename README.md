# Climate Change & Global Temperature Analysis

A data analysis project exploring global temperature trends using the Berkeley Earth dataset.

## About
This project analyzes historical global land temperature data to identify climate change patterns,
temperature anomalies, and regional differences across countries.

## Files
- `Climate_Change_Analysis.ipynb` — Main analysis notebook with all charts and findings

## Dataset
Download the CSV files from Kaggle before running the notebook:
[Berkeley Earth Climate Change Dataset](https://www.kaggle.com/datasets/berkeleyearth/climate-change-earth-surface-temperature-data)

## Key Findings
- Global temperatures have risen significantly since the 1850s
- Warming accelerated noticeably after 1980
- The 2000s are the warmest decade on record in this dataset
- Large variation in average temperatures across countries

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
